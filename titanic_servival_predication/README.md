# Titanic Survival Prediction

## Overview

This project uses the classic Titanic dataset to build a machine learning model that predicts whether a passenger survived or not based on available passenger information.

## Files

- `model.ipynb` — notebook containing the model development workflow
- `train.csv` — training dataset
- `test_inputs.csv` — test dataset for prediction input

## Dataset

The dataset contains features such as:

- `Survived` (target)
- `Pclass`
- `Sex`
- `Age`
- `SibSp`
- `Parch`
- `Fare`
- `Embarked`

## Objective

The task is to predict passenger survival using a binary classification model, while handling missing data and categorical variables appropriately.

## Technologies Used

- Python
- pandas
- scikit-learn
- Jupyter Notebook
