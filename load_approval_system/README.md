# Loan Approval System

## Overview

This project explores a loan dataset and demonstrates a machine learning workflow for understanding approval-related patterns and making a prediction based on applicant data.

## Files

- `Project (4).ipynb` — notebook with the implementation
- `loan-data.csv` — training dataset for the loan analysis

## Dataset

The dataset includes financial and applicant features such as:

- `age`
- `income`
- `experience`
- `monthly_transactions`
- `account_balance`
- `spending_score`
- `credit_score`
- `default`

The target variable is `default`, which indicates whether the customer is associated with a default risk.

## Objective

The goal is to train a predictive model that evaluates risk-related patterns from applicant information and supports loan decision analysis.

## Technologies Used

- Python
- pandas
- scikit-learn
